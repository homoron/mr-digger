# Mr. Digger

Juego incremental de excavación en pixel art, hecho con Godot 4.7. Versión web de prueba.

**[Jugar a Mr. Digger](https://homoron.github.io/mr-digger/)**

A/D: moverse · Espacio: saltar · Clic/J: herramienta · E: interactuar · 1–6: herramientas · M: mapa · Esc: pausa.

**Pantalla completa:** botón en la esquina inferior derecha o F11.

El pico de cobre cuesta 70 monedas y el de hierro, 260. Las partidas existentes se conservan en el mismo navegador.

Funciona mejor con teclado y ratón en un ordenador.
