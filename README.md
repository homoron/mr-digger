# Hacia el Núcleo

Juego de excavación en pixel art hecho con Godot 4.7. Esta es la versión web jugable (build de prueba).

**Jugar:** https://homoron.github.io/hacia-el-nucleo/

Controles: A/D mover, Espacio saltar, ratón o J para picar, E para interactuar, 1-6 herramientas, M mapa, Esc pausa. Funciona mejor con teclado y ratón en un ordenador.
